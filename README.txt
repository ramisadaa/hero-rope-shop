Hero Rope — Final / v2.0.0
=========================

تشغيل البرنامج
--------------
1) فك الضغط كاملًا في مجلد جديد؛ لا تخلط ملفاته مع النسخة القديمة.
2) افتح المجلد بـ VS Code وشغّل index.html بواسطة Live Server.
   أو، إذا كان Node.js موجودًا، شغّل:
       node scripts/serve.cjs
   ثم افتح http://127.0.0.1:4173
3) واجهة المتجر لا تحتاج npm install. هذه الخطوة مطلوبة للتطوير والاختبارات فقط.

الحبل والتصميم المرجاني والسلة وشاشة Checkout محفوظة. الواجهة موحّدة بالإنجليزية
مثل محتوى المتجر الأصلي، وهذا الملف بالعربية لشرح التشغيل.

مصدر المنتجات والأسعار
----------------------
- يبدأ العرض فورًا من آخر كتالوج ناجح محفوظ، أو من مجموعة تجريبية محلية.
- توجد مجموعة احتياطية في products.json، ونسختها القابلة للتحميل من المتصفح
  في catalog-data.js. صور المجموعة الاحتياطية رسومات محلية توضيحية.
- يُطلب الكتالوج المباشر من Fake Store API في الخلفية، مع مهلة 6 ثوانٍ
  لكل محاولة ومحاولة تلقائية إضافية. يبقى العرض الاحتياطي قابلًا للاستخدام.
- الشريط أعلى البحث يوضح أن المصدر محفوظ أو تجريبي وأن أسعاره قديمة/توضيحية.
- آخر استجابة ناجحة محفوظة في shopCatalogV2. لا تُستبدل ببيانات عند فشل الشبكة.
- إذا تغيّر سعر منتج في السلة، يظهر السعر القديم والجديد، ويُمنع Checkout
  إلى أن يضغط المستخدم Accept updated prices. لا يُقبل التغيير ضمنيًا.
- هذه آلية تجربة محلية؛ ليست تحققًا من أسعار متجر تجاري أو مخزونه.

ما تم إصلاحه
------------
- حذف إغلاق السلة اعتمادًا على focusout؛ الإغلاق بالنقر خارجها أو Escape.
- زر الحبل يحتفظ بالتركيز أثناء الأنيميشن، ويستخدم aria-disabled وحارسًا للنقر.
- البحث يدعم كلمات متعددة بأي ترتيب، مع أولوية العنوان ومطابقة بداية الكلمة؛
  البحث men لا يطابق women أو compartment.
- تباين نصوص Hero محسّن، مع أسطح معتمة للنصوص المحيطة بالحبل.
- الحبل أصغر على الهاتف، بارتفاع 230–260px، مع زر إيقاف وتقليل الحركة.
- حركة السكون تستخدم Web Animations؛ لا تعيد كتابة left/top أو مسار SVG كل إطار.
  تُحدَّث هندسة الحبل فقط أثناء السحب والارتداد القصير.
- اختيار عشوائي بنظام shuffle bag يمرّ بجميع المنتجات قبل إعادة الدورة.
- تحميل صورة المنتج مسبقًا قبل الكشف، وبديل واضح عند تعذّرها.
- دعم كامل للزيادة والنقصان والحذف والتفريغ، مع Undo ودون إعادة إنشاء صور
  السلة عند تغيير الكمية. توجد مزامنة بين التبويبات مع فحص storageArea.
- live regions ثابتة، مع رسائل خطأ مستقلة، وصور زخرفية بجوار أسماء المنتجات
  لتقليل التكرار الصوتي. زر الصورة مختصر للفأرة؛ يوجد زر تفاصيل بلوحة المفاتيح.
- أهداف لمس أكبر، وخطوط أوضح، ودعم reduced-motion وscrollbar-gutter.
- تفاصيل المنتجات لها روابط من الشكل #product-1.
- سنة الحقوق تلقائية، وصياغة 1 item صحيحة، وحالة بدون JavaScript بلا سبينر دائم.
- رابط Contact غير الحقيقي استُبدل بـ About؛ لا يوجد بريد أو حساب تاجر مخترع.
- صفحات معلومات داخلية تشرح المشروع والخصوصية وحدود التجربة.
- أيقونات محلية وmanifest وصورة مشاركة ووسوم اجتماعية ورابط X وأيقونة SVG.
- CSP داخل HTML، وصور بلا referrer، وترويسات ضد التأطير في الخادم المحلي
  وملف _headers للاستضافات التي تدعمه.

بيانات المشتري والدفع التجريبي
-----------------------------
- لا تستخدم بطاقة حقيقية. يقبل النموذج رقم الاختبار التالي فقط:
       4242 4242 4242 4242
       CVV: 123
       تاريخ مستقبلي بصيغة MM/YY أو MM/YYYY
- لا يُختصر لصق 12/2030 إلى 12/20. لا يُعاد تنسيق التاريخ أثناء الكتابة.
- يُجمّع رقم الاختبار إلى مجموعات عند مغادرة الحقل بدل تحريك المؤشر أثناء الكتابة.
- لا تُرسل بيانات المشتري أو البطاقة إلى خادم، ولا تُحفظ بيانات البطاقة.
- الاسم والإيميل فقط في customerDraft داخل Session Storage، مع تأخير قصير
  أثناء الكتابة وحفظ عند التغيير/الخروج. تُحذف المسودة بعد تأكيد الطلب.
- السلة في shopCart بصيغة مختصرة: id وquantity والسعر المقبول quoteCents.
  لا تتكرر أوصاف المنتجات الكاملة داخل السلة المحفوظة.
- يدعم ترحيل السلة القديمة، ويزيل المفتاح my-shop-cart-v1 بعد نجاح حفظ الترحيل.
- يُحفظ آخر إيصال تجريبي قبل تفريغ السلة، بمعرّف عشوائي وتاريخ ومنتجات وإجمالي.
  لا يحتوي الإيصال اسم المشتري أو إيميله أو بيانات بطاقة.
- زر Last demo receipt في الفوتر يعيد فتح الإيصال بعد تحديث الصفحة.
- من Privacy يمكن مسح بيانات هذا المتجر المحفوظة.

اختبارات قابلة لإعادة التشغيل
----------------------------
يلزم Node.js 22.13 أو أحدث لتثبيت أدوات التطوير:
    npm ci
    npm run lint
    npm test
    npx playwright install chromium
    npm run test:browser

للتحقق بمحرك آخر بعد تثبيته:
    npx playwright install firefox webkit

في Linux/macOS:
    BROWSER=firefox npm run test:browser
    BROWSER=webkit npm run test:browser

في PowerShell:
    $env:BROWSER="firefox"
    npm run test:browser
    Remove-Item Env:BROWSER

توجد البيانات التجريبية وسكربتات المتصفح وaxe وقياس التباين في tests/.
تتولد النتائج والصور في test-results/ عند التشغيل. يتضمن الأرشيف ملخص نتائج
الفحص المنفّذ في verification/؛ الصور ليست جزءًا من الأرشيف.
لا يُعامل غياب مخالفات axe كضمان اجتياز كل متطلبات الوصول؛ البنود غير المحسومة
تُسجّل منفصلةً، والتباين فوق التدرج يُفحص بعينات من الصورة المرسومة.

البناء والنشر
-------------
    npm run build

يُنشئ dist/، مع JavaScript/CSS مصغّر وإصدارات أصول مبنية على تجزئة المحتوى.
انشر محتويات dist/ عند الاستضافة. لا تحتاج الاستضافة إلى node_modules.
لإنشاء رابط صورة مشاركة مطلق قبل النشر، اضبط SITE_URL إلى عنوان HTTPS الفعلي:
    SITE_URL=https://your-domain.example/ npm run build
في PowerShell اضبط $env:SITE_URL أولًا.
لا يوجد عنوان نشر مفترض داخل المشروع؛ معاينة المشاركة الكاملة تتطلب رابطًا عامًا.

الخادم scripts/serve.cjs يرسل ترويسات frame-ancestors وX-Frame-Options وnosniff.
ملف _headers مناسب للاستضافات التي تقرأه، ويجب ضبط الترويسات يدويًا في غيرها.
سياسة frame-ancestors لا يمكن تطبيقها بواسطة meta. ملف manifest يوفّر بيانات
وأيقونات للتطبيق؛ لا يدّعي المشروع توفير Service Worker أو تثبيت PWA كامل.
